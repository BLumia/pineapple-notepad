# 菠萝记事本

菠萝记事本是一款高级、易用的多文档文本编辑器。提供了编码检测、会话恢复、宏录制等诸多功能，内置丰富的纯文本处理工具与超 300 种不同类型文件的语法高亮支持，并且支持 Windows、macOS 与 Linux 桌面平台。

菠萝记事本旨在提供 Notepad++ 的跨平台替代。此项目基于 [Scintilla](https://www.scintilla.org/)、[Qt](https://www.qt.io/) 和 [KDE Framework](https://develop.kde.org/products/frameworks/)。

## 赞助

在现有赞助者们的大力支持下，菠萝记事本现已达成了其开源目标：此项目的完整代码已经在 OSI 认可的开源许可协议下发布，并且 GitHub 上所提供的版本将会直接包含所有特性。

让《菠萝记事本》可以在更多系统、平台、架构、渠道中获取并正常使用是一件需要需要投入额外精力的工作，因而，在一些需要额外耗时耗力维护的平台或渠道中，会提供名为 Effort Edition 的版本。此版本中，编辑器的核心功能和工具将仍然完整可用，而个别锦上添花（主题编辑器与上下文菜单编辑器）的功能需要通过导入“赞助者许可证”来解锁。您可以通过赞助此项目的方式来获得许可证，一次赞助即可获得赞助者许可证，许可证在所有版本中导入使用。

全功能版本中无需导入许可证即可使用完整功能，不过我们也仍然保留了许可证导入功能。在全功能版本导入许可证的好处是可以避免在更新版本后首次运行新版本时弹出赞助致谢对话框，并在赞助致谢对话框中显示对您的致谢。

如果你喜欢这个项目，并且希望此项目能够持续维护下去的话，请考虑 [成为赞助者](https://pineapple-notepad.blumia.net/sponsor)！
